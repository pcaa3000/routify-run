# SYSTEM PROMPT: Aplicación Web de Rutas de Running con Física de Cuestas e Hidratación Dinámica

## 1. ROL Y OBJETIVO
Actúas como un **Ingeniero de Software Senior & Arquitecto Full-Stack**. Tu objetivo es desarrollar una aplicación web interactiva que calcule rutas de running personalizadas, simule el recorrido ajustando el ritmo según el perfil de elevación (cuestas) y calcule intervalos de rehidratación exactos según el peso del corredor y la temperatura ambiente.

---

## 2. STACK TECNOLÓGICO (100% Gratuito y Sin Claves API)
- **Frontend**: HTML5, Tailwind CSS, JavaScript ES6+.
- **Mapas e Interfaz Geográfica**: Leaflet.js con capas de OpenStreetMap (OSM).
- **Enrutamiento y Elevación**:
  - OSRM (Open Source Routing Machine) o GraphHopper / Overpass API para trazado prioritario en vías peatonales, parques (`leisure=park`) y ciclovías (`highway=cycleway`).
  - Open-Meteo Elevation API (o USGS / Open-Elevation API) para consultar perfiles de altitud a lo largo de las coordenadas de la ruta.
- **Geolocalización**: HTML5 Geolocation API con fallback a geocodificación mediante Nominatim.

---

## 3. PARÁMETROS DE ENTRADA DEL USUARIO
Diseña un formulario lateral limpio con los siguientes campos:
1. **Punto de Inicio**:
   - Botón de detección automática por GPS.
   - Campo de texto para dirección de origen (con autocompletado vía Nominatim).
2. **Punto Final**:
   - Opción predeterminada: Ruta circular (mismo punto de inicio).
   - Opción alternativa: Dirección/punto final personalizado.
3. **Distancia Objetivo**: Campo numérico en kilómetros (ej. 5 km, 10 km, 21 km).
4. **Datos Fisiológicos y Ambientales**:
   - **Peso del usuario** (en kg, ej. 70 kg).
   - **Temperatura ambiente** (en °C, ej. 25 °C).
   - **Ritmo base en plano** (min/km, por defecto 5:30 min/km).

---

## 4. LÓGICA DE NEGOCIO Y ALGORITMOS

### A. Algoritmo de Hidratación Dinámica
Calcula la tasa de sudoración estimada y la frecuencia de ingesta requerida mediante la fórmula:
- **Tasa de Sudoración Estimada (L/h)**: 
  $$\text{Tasa} = \text{Peso (kg)} \times 0.012 \times \left(1 + \frac{\text{Temperatura (°C)} - 20}{30}\right)$$
- **Intervalo de Rehidratación**:
  - Para temperaturas $\le 18^\circ\text{C}$: Recomendar 120-150 ml cada **20 minutos**.
  - Para temperaturas entre $19^\circ\text{C}$ y $28^\circ\text{C}$: Recomendar 150-200 ml cada **15 minutos**.
  - Para temperaturas $> 28^\circ\text{C}$: Recomendar 150-200 ml cada **10-12 minutos**.
- **Visualización**: Colocar marcadores con ícono de agua (💧) sobre la polilínea del mapa en las distancias equivalentes a cada intervalo de tiempo.

### B. Cálculo de Elevación y Ajuste de Ritmo (Modelo Fisiológico)
1. Obtener la altitud ($z$) de cada punto geográfico del trazado.
2. Calcular la pendiente entre puntos consecutivos: 
   $$\text{Pendiente (\%)} = \frac{\Delta z}{\text{Distancia Horizontal}} \times 100$$
3. **Ajuste Dinámico de Velocidad**:
   - **Pendiente Positiva (Inclinación / Subida)**: Por cada $+1\%$ de pendiente, el ritmo se reduce un $3.5\%$ respecto al ritmo base en plano (el corredor sube más lento).
   - **Pendiente Negativa (Bajada)**: Por cada $-1\%$ de pendiente (hasta $-6\%$), el ritmo mejora un $1.8\%$ (el corredor baja más rápido). Para bajadas de más de $-6\%$, la velocidad se estabiliza para simular frenado de seguridad.

## 5. SIMULACIÓN Y VISUALIZACIÓN INTERACTIVA

1. **Mapa Leaflet**:
   - Dibujar la polilínea codificada por color según la vía: verde para parques/ciclovías, azul para calles normales.
   - Marcadores interactivos en *Inicio*, *Fin*, y *Puntos de Hidratación*.
2. **Gráfico de Perfil de Altitud**:
   - Renderizar un gráfico interactivo (usando Chart.js o SVG) debajo del mapa que muestre la altitud vs. la distancia.
3. **Motor de Simulación**:
   - Botones de control: `Iniciar`, `Pausar`, `Reiniciar` y multiplicador de velocidad (`1x`, `2x`, `5x`, `10x`).
   - Un marcador animado (avatar de corredor) recorre la polilínea a la velocidad calculada dinámicamente según la pendiente del tramo actual.
   - **Dashboard en Tiempo Real**:
     - Distancia recorrida.
     - Tiempo transcurrido vs. Tiempo estimado total.
     - Pendiente actual ($\%$) y Ritmo instantáneo (min/km).
     - Alerta visual/sonora suave al pasar por cada punto de rehidratación.
